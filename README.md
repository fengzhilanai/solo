# Solo · 个人创业者与小团队 AI 服务官网

> 面向个人创业者、独立顾问、自由职业者与小团队，提供从真实业务问题出发的 AI 诊断、共创、定制实现与实战训练服务。

`solo` 是风之岚科技面向个人创业者与小团队的独立服务官网，介绍服务路径、适合场景、成果形态、合作流程、交付边界和咨询入口。

## 服务定位

从一个真实业务问题开始，先做出一个可以实际试用、也方便后续接手的第一版。

本页面介绍的服务包括：

- AI 项目诊断
- AI 项目共创
- AI 定制实现
- AI 实战训练营

具体服务范围、价格、周期、交付物、验收方式、第三方费用和协议主体，以项目启动前的书面确认内容为准。

## 本地预览

这是一个无构建步骤的静态网站，不需要安装依赖。

在项目根目录运行：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000/
```

## 内容与合作边界

- 本站用于服务介绍和咨询，不是自动付款页面。
- 提交咨询不等于成交、录取或名额锁定。
- 具体范围、交付、验收、付款、退款/取消/改期、数据处理和成果归属等事项，以付款前书面确认的方案和协议为准。
- 域名、托管、模型调用、软件订阅、存储、短信、支付、审核和上架等第三方费用不默认包含在服务价格内。
- 网站不承诺流量、收入、获客、销量或固定节省比例等经营结果。

## 安全与隐私

这是一个公开仓库。请不要向仓库提交以下内容：

- API Key、Access Token、密码或其他凭证；
- 客户联系方式和未脱敏业务数据；
- 内部合同、报价方案或未公开项目资料；
- 未获授权使用的图片、字体、文案或第三方素材。

咨询阶段也不要通过表单或普通聊天提交密码、API Key、访问令牌或未脱敏的敏感业务数据。
